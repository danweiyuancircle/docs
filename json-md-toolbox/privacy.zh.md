# JSON & Markdown Toolbox 隐私政策

最后更新：2026-10-21

英文版本：[Privacy Policy](privacy.en.md)。用户协议：[用户协议](terms.zh.md)。

JSON & Markdown Toolbox（下称「本扩展」）在你用地址栏直接打开 JSON 或 Markdown 时，把这一页显示成可读的页面。本扩展免费，没有账号，也不含广告。

## 我们读取什么

本扩展只读取**当前标签页这一份文档**的正文，用来判断它是不是 JSON 或 Markdown，并在页面上显示。它不读取该网页随后发出的其它请求，不读取浏览历史，不读取书签、Cookie 或密码。

专业编辑器只处理你主动粘贴、选择、拖放的文档，或你点击阅读页的“专业编辑器”时从该页面带入的原文。原文通过本机扩展消息传给新标签页，用于编辑、格式化、比较和预览，不发送到作者或其它服务器。

## 我们保存什么

你可以按域名关闭查看器。被关闭的域名名单保存在浏览器的同步存储中。

如果你的浏览器开启了 Chrome 同步，这份名单会随你的 Google 账号在你自己的设备之间同步。同步由浏览器完成，本扩展的作者收不到这份名单，也看不到你打开过哪些网页。

外观、字号、换行、阅读密度和 JSON 默认视图等阅读偏好保存在浏览器的本地存储中，不通过 Chrome 同步。

本扩展不保存页面正文，不向扩展作者上传页面内容，不使用分析或广告服务。

编辑器内容只保留在标签页内存中，不写入本地、同步或会话存储。刷新或关闭编辑器后，内容即丢弃。复制和下载只在你主动选择对应操作时进行。

## 文档中的图片和链接

JSON 图片预览和 Markdown 图片默认不加载。JSON 图片预览会在你悬停图片地址、用键盘聚焦或点击预览等明确操作后请求对应图片；Markdown 图片仍需点击「加载图片」。图片服务可能收到你的 IP 地址及图片 URL 中包含的信息；请求不发送当前页面的 Referer。本扩展的作者不会接收这些请求。文档中的外部链接也只在你点击时打开。

## 我们不做什么

- 不向扩展作者发送你的网页内容；你主动加载图片时的请求见上文
- 不出售数据
- 不把数据用于信贷、广告或与查看器无关的用途

## 你可以怎么删除

在扩展图标的弹窗里重新启用某个域名，该域名会从禁用名单中移除。卸载扩展后，浏览器会删除本扩展保存的数据。

## 政策变更

如果数据做法发生变化，会更新本页并修改上方的日期。
