# JSON & Markdown Toolbox User Agreement

Updated: 2026-10-16.

This agreement applies to the Chrome extension JSON & Markdown Toolbox (the "extension"), published by UnitCircle. Read the [Privacy Policy](privacy.en.md) before use. This agreement does not reduce rights granted by applicable law.

## 1. What the extension provides

When you open a JSON or Markdown document directly from the address bar, the extension shows that page in a readable view. Ordinary websites, and other content a page loads later, are not taken over.

The extension is free. It has no account, no in-app purchases, and no ads. The interface follows Chrome's language. Current languages are English, Simplified Chinese, Traditional Chinese, Japanese, and Korean.

The installed version's behavior is the behavior of that version. Descriptions in these documents are not a promise of future features.

## 2. Your responsibilities

Open only documents you are allowed to view, and follow the copyright, confidentiality, and legal terms that apply to them. The extension does not grant new rights in third-party content.

Turning the viewer off for a domain, changing appearance, copying, downloading, and loading images in a document are actions you take in the browser. An image is requested from the address given in the document only after you click to load it.

## 3. Distribution and third parties

When you install from the Chrome Web Store, installation, updates, and removal follow Google's and the Chrome Web Store's terms. Chrome Sync is provided by Google. These user documents and public reports are hosted by GitHub. Each service has its own terms and privacy policy.

Publishing this directory does not publish the extension source code or an installable package.

## 4. Availability

A page may not display as expected when the document format, browser version, or page structure changes. This section does not remove duties the publisher has under applicable law, and it does not assign every failure to the user.
