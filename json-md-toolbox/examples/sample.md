## 一段小代码

用简单的 JavaScript 记录阅读进度：

```javascript
const readingList = [
  { title: '月光下的花园', finished: true },
  { title: '写给未来的明信片', finished: false }
];

const completed = readingList.filter(book => book.finished);
console.log(`已读完 ${completed.length} 本书`);
```
