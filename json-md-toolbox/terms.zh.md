# JSON & Markdown Toolbox 用户协议

更新日期：2026-10-16。

本协议适用于 Chrome 扩展 JSON & Markdown Toolbox（下称「本扩展」），由发布者 UnitCircle 提供。使用前请同时阅读[隐私政策](privacy.zh.md)。本协议不减少适用法律规定的权利。

## 1. 扩展提供什么

本扩展在你用地址栏直接打开 JSON 或 Markdown 文档时，把这一页显示成可读页面。普通网站、以及页面里随后加载的其它内容，不会被接管。

本扩展免费，没有账号，没有应用内购买，不含广告。界面语言跟随 Chrome，当前包括英语、简体中文、繁体中文、日语和韩语。

已安装版本的实际功能以该版本为准。文档中的说明不是对未来功能的承诺。

## 2. 你的使用责任

请只打开你有权查看的文档，并遵守这些内容适用的版权、保密约定和法律要求。本扩展不授予对第三方内容的新权利。

关闭某个域名的查看器、切换外观、复制、下载，以及加载文档中的图片，都由你在浏览器中操作。图片只有在你点击后才会向文档指定的地址发出请求。

## 3. 分发与第三方服务

通过 Chrome 网上应用店安装时，安装、更新和卸载适用 Google 与 Chrome 网上应用店的条款。Chrome 同步由 Google 提供。本用户文档和公开反馈由 GitHub 托管。这些服务分别适用其自己的条款和隐私政策。

公开本目录不表示扩展源码开放，也不在此提供安装包。

## 4. 可用性

文档格式、浏览器版本或页面结构变化时，某个页面可能无法按预期显示。这些说明不免除适用法律要求提供者承担的责任，也不把所有故障都转给用户。

## 5. 变更、反馈与争议

数据处理方式变化时，会更新隐私政策并修改其上的日期。本协议的重要变更会更新本页日期。

反馈请提交到 <https://github.com/danweiyuancircle/docs/issues>，标题写明 JSON & Markdown Toolbox。可以写扩展版本、Chrome 版本和操作步骤。不要公开个人文件、密钥、未脱敏的业务数据、完整个人路径或账号信息。

如发生争议，可先通过上述入口联系。依法享有的投诉和救济途径不受本协议限制。
