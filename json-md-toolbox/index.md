# JSON & Markdown Toolbox 文档 / Documentation

Chrome 扩展 JSON & Markdown Toolbox 的隐私政策与用户协议。本扩展在你用地址栏直接打开 JSON 或 Markdown 时，把这一页显示成可读页面。普通网站不会被接管。扩展免费，没有账号，也不含广告。

Privacy Policy and User Agreement for the Chrome extension JSON & Markdown Toolbox. When you open a JSON or Markdown document directly from the address bar, the extension shows that page in a readable view. Ordinary websites are left unchanged. The extension is free, has no account, and contains no ads.
