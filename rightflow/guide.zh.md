# 轻右键 / RightFlow 使用指南

更新日期：2026 年 10 月 21 日。适用 macOS 14 及以上；界面和功能以你安装的版本为准。当前开发构建已接入 7zz 本地解压；本指南中的解压说明仅适用于已经提供该功能的版本，不代表 App Store 版本已经发布。

## 1. 启用 Finder 扩展

1. 打开轻右键，查看底部的 Finder 扩展状态。
2. 扩展未开启时，使用应用提供的系统设置入口，并在 macOS 扩展管理界面启用轻右键。不同系统版本的扩展管理入口名称可能不同。
3. 回到 Finder，在当前目录空白处或选中的文件上点右键，打开「轻右键」或「RightFlow」子菜单。

主应用负责设置和执行需要文件访问的操作；Finder 扩展负责提供菜单。应用已启动不代表扩展已开启。

## 2. 编辑右键菜单

主窗口中的动作行就是菜单配置，没有额外保存按钮。

- **开关**：关闭不需要的动作，下一次 Finder 右键时生效。
- **排序**：拖动行把手调整顺序；也可通过行菜单中的「上移 / 下移」完成。
- **同行选择器**：选择默认模板、终端或编辑器，或进入模板和位置管理。
- **通用设置**：通过齿轮查看语言、外观、帮助、扩展引导和购买相关入口。

菜单会根据空白处、文件、图片和待粘贴状态显示适用动作，因此设置中的行数不等于 Finder 同时显示的行数。实际短菜单最多六行；单张图片的「拷贝为 PNG」由上下文自动提供。

可用 Tab 访问控件，Space 切换开关；原生菜单支持方向键和 Return。应用未安装或目录授权失效时，应重新选择有效应用或位置。

## 3. 常用动作

### 拷贝路径与名称

点「拷贝路径」把目标路径写入系统剪贴板。按住 Option 点同一项，改为 file URI。「拷贝文件名」只在选中对象时出现。

### 新建文件

在 Finder 目录空白处使用新建动作。默认纯文本；选中纯文本时，按住 Option 可改为 Markdown。也可在同行选择器中将 Markdown 设为默认。

Pro 可选择自定义模板。模板名最多 40 字符、扩展名最多 16 字符、初始内容最多 8000 字符。若默认模板被删除，重新选择有效模板，不要把此前显示的名称当成有效模板仍然存在的证明。

### 终端与编辑器

设置一个有效已安装的终端，在目录空白处使用终端动作。选中的文件或目录可通过 Pro 编辑器动作打开。系统终端可作为默认选择；使用外部应用后，其行为由该应用负责。

### 移到最近位置

选中文件或目录，打开「移到最近位置」，选择保存的位置，或使用「选取文件夹…」。首次选择目录时通过系统选择器授权，成功移动后记录最近位置。

免费层使用一个保存位置；Pro 可保存更多位置，菜单显示最近三个。授权失效时重新选择相关目录，不需要也不承诺获取全磁盘权限。

### 剪切 / 粘贴

Pro 用户可主动开启该组。选中文件后使用「剪切」记录待移动对象；切换至目标目录，在空白处使用「粘贴」执行移动。成功粘贴后清除缓冲。剪切不是删除，关闭开关也不会撤销已经完成的移动。

### 拷贝为 PNG

选中一张支持的图片，使用「拷贝为 PNG」将图片编码到系统剪贴板，不覆盖原图、不新建转换文件。过大的图片、损坏图片或无法读取的文件会导致操作失败。

## 4. Pro 本地解压

当前开发构建已接入解压；只有安装版本实际提供该动作时才能使用。

1. 在文件工具设置中启用 Pro「解压」。
2. 在 Finder 选中一个支持的压缩包。
3. 点「解压到同名文件夹」。应用在本机使用 7zz 处理，不上传压缩内容。
4. 查看生成目录或错误提示；重要资料先备份，不连续重复点击未完成的操作。

当前开发构建支持的常见格式包括 ZIP、7z、RAR、TAR、GZip、BZip2、XZ 及对应的 TAR 复合后缀。分卷、加密压缩包及其他特殊格式不在本文的可用性承诺内；具体限制以该版本界面和错误提示为准。

该链路复用维护者自己的 [EasyArchiver（原 EasyZip）工程](https://github.com/danweiyuancircle/easy-zip) 中的 7zz 本地处理方案，不是来自同名竞品。引擎版本为 7-Zip 25.01，相关许可与源码见 [隐私政策的第三方开源组件附录](https://danweiyuancircle.github.io/docs/rightflow/privacy.zh.html#附录第三方开源组件)。

当前保护边界：源压缩包不超过 2 GiB、清单中的累计未压缩大小不超过 10 GiB、条目数不超过 100000。开发验证已包含真实压缩包测试、AES ZIP 定向测试和实际 Finder ZIP 操作，测试环境为 arm64 Mac；这些证据不代表全部格式、异常路径或其他硬件已经完成验收，也不代表 App Store 版本已经发布。

## 5. 免费体验、购买与恢复

提供本方案的版本从首次使用开始提供 Pro 免费体验，期限为两个自然月，以应用显示的到期时间为准，不是统一活动截止日，也不是固定 60 天。体验期无需先购买订阅，本身不会自动扣费；到期后保留免费基础功能，继续使用 Pro 需要你主动选择并确认购买。体验资格由本机记录判定，不承诺跨 Mac 共享免费期或卸载后重新获得免费期。

体验期后，可按安装版本提供的商品选择一个月自动续订的 Pro 月订阅，或一次性购买 Pro 永久买断。具体价格、货币与可用性以 Apple 购买确认界面为准。月订阅由你确认后才开始收费；确认后会自动续订，需至少在周期结束前 24 小时通过 [Apple 订阅管理](https://apps.apple.com/account/subscriptions) 取消，以免下一周期续费。卸载应用或购买永久买断不会自动取消已有订阅；从订阅转为买断时需要自行取消订阅。

购买权益通过 Apple StoreKit 验证。按应用提供的入口恢复同一 Apple 账号的购买，购买记录与恢复由 Apple 管理。购买或恢复需要 Apple 服务；文件操作本身在本机完成。退款可通过 [Apple 申请退款](https://reportaproblem.apple.com/) 处理。详细规则见 [用户使用协议](https://danweiyuancircle.github.io/docs/rightflow/terms.zh.html)。

本仓库发布文档不代表应用已上架或版本已发布。若已购买而仍显示未解锁，先核对安装版本与 Apple 账号，再通过支持入口反馈。

## 6. 常见问题

| 问题 | 处理 |
| --- | --- |
| Finder 中没有菜单 | 检查系统扩展开关，重新打开轻右键和 Finder 窗口，再检查扩展状态 |
| 所选终端或编辑器不可用 | 检查应用是否仍安装，重新选择有效应用；一次扫描失败不表示原配置已被删除 |
| 位置没有权限 | 重新通过系统选择器选取该目录；检查磁盘连接和 macOS 权限限制 |
| 反复弹出访问其他应用数据的提示 | 先停止重复操作，检查版本、签名与扩展状态，通过支持入口反馈；不要为了排障授予全磁盘权限 |
| 文件操作失败 | 检查源文件、目标目录、空间和权限；先确认文件现状，再决定是否重试 |
| 需要排查日志 | 本机日志可能包含个人路径；先脱敏，再主动提交需要的片段 |
