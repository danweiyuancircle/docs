# 轻右键 / RightFlow 隐私政策

更新日期：2026 年 10 月 21 日。

本政策说明轻右键如何处理数据。轻右键由本仓库维护者提供，是本地 macOS Finder 右键工具；不要求注册开发者账号，不提供开发者自建文件服务器，不使用应用内广告、第三方行为分析或自动遥测服务。应用具有文件读写权限；“本地处理”不代表完全不读取文件或不需要授权。

## 1. 本机处理的数据

| 数据 | 用途与位置 |
| --- | --- |
| 菜单顺序、开关、所选终端与编辑器、模板内容和语言等设置 | 保存在本机 App Group 共享配置中，供主应用和 Finder 扩展共同使用 |
| 所选文件或目录的名称与路径 | 执行拷贝路径、打开应用、新建文件、移动等操作 |
| 目录授权书签 | 保存 macOS security-scoped bookmark，在授权范围内复用目录访问权；书签是授权记录，不是文件内容副本 |
| 剪切缓冲与操作交接信息 | 在本机记录待移动文件路径及授权信息；主应用和扩展在本机共享容器中交接操作 |
| 剪贴板内容 | 根据你点选的操作写入路径、名称或 PNG 图片；系统剪贴板可能被其他有相应权限的应用读取 |
| 文件与图片内容 | 新建、移动、拷贝 PNG 等操作按需读取或写入对应文件；不自动扫描全部磁盘 |
| 本机诊断日志 | 用于排查操作失败，可能包含动作、时间、文件名称或路径、错误信息；不会自动上传给开发者 |
| 免费体验记录 | 首次使用日期和最近观察时间保存在本机钥匙串，用于判定两个月体验期；体验与权益状态经本机 App Group 共享给 Finder 扩展，不上传到开发者服务器 |
| 购买权益状态 | 应用通过 Apple StoreKit 验证买断或订阅交易，读取有效期、撤销等权益信息，并在本机保存权益状态供主应用和 Finder 扩展使用 |

当前开发构建已接入 Pro 本地解压，使用本机 7zz 引擎读取你选中的压缩包，并将结果写入目标目录，不将压缩包上传至开发者服务器。开发构建验证不等于 App Store 发布；具体支持格式与交互以安装版本为准。

菜单构建不代表授权读取任意目录。文件操作仍受 macOS 沙盒、用户授权、文件权限和系统隐私保护限制；授权失效时需要重新选择相关目录。

## 2. 数据是否离开设备

轻右键不会自动把文件、模板、路径、书签或诊断日志上传给开发者，不出售这些数据，不以本机数据建立广告画像。

以下行为涉及其他服务或应用：

- **购买与恢复购买**：由 Apple 的 App Store 和 StoreKit 处理。轻右键接收购买结果及权益信息，不收取或保存信用卡号码。Apple 如何处理购买和账号数据，见 [App Store 与隐私](https://www.apple.com/legal/privacy/data/en/app-store/)。
- **打开终端或编辑器**：轻右键会把相关文件或目录交给你指定的应用；该应用后续行为适用其自身隐私政策。
- **浏览本文档或提交反馈**：页面和公开 Issue 由 GitHub 托管。GitHub 可能处理访问日志、IP 地址、账号和你提交的内容，适用 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。

应用的网络权限声明本身不等于正在上传数据。本政策描述实际使用行为，不承诺 Apple、GitHub、操作系统或外部应用完全不联网。

## 3. 你主动提供的支持信息

通过 [unitcircle@agent.qq.com](mailto:unitcircle@agent.qq.com) 联系作者时，维护者会读取你的发件地址及主动提供的问题描述、附件和诊断片段，用于处理支持请求。邮件由相关邮件服务商传输和保存，适用其隐私政策；应用不会自动发送支持邮件或附件。

通过 [GitHub Issue](https://github.com/danweiyuancircle/docs/issues) 反馈时，维护者会读取你主动提交的版本、问题描述、截图或日志，用于排查和回复。公开 Issue 及附件会公开显示，也可能被搜索引擎索引。

不要发布个人文件内容、账号信息、密钥、付款凭证或完整个人路径。发送诊断日志前，先检查并遮盖敏感内容。轻右键不会因你未上传日志而自动上传其他数据。

## 4. 保存、删除与控制

本机设置与授权记录按功能需要保留，以便下次使用；首次使用日期与最近观察时间按体验期判定需要保存在本机钥匙串中，卸载应用后可能仍会保留。该记录不用于在不同 Mac 之间唯一识别人，也不是服务器统一维护的防重装记录。剪切缓冲在成功粘贴后清除。本机诊断日志受日志轮转管理，不承诺固定保存天数。

你可以关闭相应菜单动作、移除保存的位置、停止使用应用，并在 macOS 系统设置中管理系统授予的权限。应用退出或卸载不一定自动清除 App Group 配置和日志，也不会自动删除你已经创建、移动或解压的文件。需要清理本机应用数据时，可通过支持入口询问操作方法，无需公开具体个人路径。

公开反馈中的数据由 GitHub 保存；你可以使用 GitHub 提供的编辑、删除与隐私请求方式管理相关内容。若需维护者协助处理本仓库中的支持信息，可在支持入口提出请求，避免重复公开敏感内容。

功能或数据处理方式发生实质变化时，我们会更新本政策和更新日期；需要额外授权的操作遵循系统授权流程。此政策不减少适用法律赋予你的隐私权利。

联系作者：[unitcircle@agent.qq.com](mailto:unitcircle@agent.qq.com)。也可通过 [轻右键文档仓库 Issue](https://github.com/danweiyuancircle/docs/issues) 反馈；不要在公开反馈中填写个人电话或住址。
