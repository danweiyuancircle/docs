# Quadorder 隐私政策

更新日期：2026 年 10 月 18 日。

本政策适用于由 danweiyuancircle 提供的 Quadorder iOS、iPadOS 和 macOS 应用。Quadorder 用四象限管理待办任务，不要求注册应用账号，不提供应用内广告、第三方行为分析或开发者自建云同步服务。

## 1. 本机处理的数据

| 数据 | 用途与保存位置 |
| --- | --- |
| 任务标题、备注、所属象限、排序、日期、提醒时刻和重复规则 | 在本机应用容器的 Application Support 目录保存任务状态 |
| 已完成任务的快照、完成时间与重复任务关联 | 显示最近 30 天的完成历史，并判断能否恢复任务 |
| 语言、外观、提醒标识映射及评分提示计数 | 保存在本机系统偏好设置中，用于恢复设置、维护本应用的提醒与控制评分提示 |
| 购买结果与解锁权益 | 通过 Apple StoreKit 在设备上确认买断权益 |
| 你选择导入的 JSON 文件 | 在本机读取并校验，以替换当前任务和完成历史 |

Quadorder 不会自动把任务、备注或备份上传给开发者，不出售这些数据，也不使用任务内容建立广告画像。应用没有自建账号系统，因此无需提交账号注销请求来删除本机任务。

## 2. 提醒和系统权限

**iOS / iPadOS：**你启用任务提醒时，应用可申请系统「提醒事项」和通知权限。允许提醒事项访问后，应用会在自己的清单中创建或更新任务标题、备注和到期时间，并维护这些条目的关联标识；不会导入或展示你的其他提醒清单。通知已允许时，应用使用本地通知提醒，避免同时给对应提醒事项设置重复闹钟。只允许通知也可使用本地通知。

系统提醒事项权限属于完整访问权限；应用实际只维护自己记录的条目。其清单使用系统默认提醒事项账户，或可用的本机账户。如果默认账户使用 iCloud 或其他在线服务，写入的提醒可能由该账户同步到其他设备；这与 Quadorder 本身提供任务云同步不同。相关系统设置见 [Apple 提醒事项账户说明](https://support.apple.com/en-ie/guide/iphone/iph8739025dd/ios)。

**macOS：**应用仅申请通知权限并安排本地通知，不申请或新建系统提醒事项。若旧版本已获得提醒事项权限并保存过条目标识，应用会尝试清理先前由本应用创建的条目；清理失败时会在后续同步重试。

通知可显示任务标题与备注，锁屏或通知中心中的可见范围取决于系统预览设置。你可以在系统设置中撤回权限或关闭预览；拒绝提醒权限不会阻止基本任务管理。已过时刻的本地通知不会补响。

## 3. 导出、备份和恢复

导出的 JSON 备份包含任务标题、备注、日期、提醒时刻、重复规则、排序、完成历史和任务关联标识等内容。备份不是匿名文件，应用不会为其额外加密。文件保存到你选择的位置，不会自动发送给开发者。若你选择云盘、网络位置或分享给其他应用，后续保存、同步和传输适用对应服务的规则。

恢复备份会替换本机任务和完成历史，不会合并两份任务，也不会恢复买断权益、语言、外观或系统授权。该替换操作不能在应用内撤销，超出历史保留范围的记录会在恢复时清理。恢复前先导出当前数据。旧备份可保留已从应用中清理的记录，保留时间由你管理。

购买、付款和恢复购买由 Apple App Store / StoreKit 处理。应用接收核验购买所需的商品和权益信息，不接收银行卡号码或 Apple 账号密码。Apple 的处理方式见 [App Store 与隐私](https://www.apple.com/legal/privacy/data/en/app-store/)。

## 5. 保存、删除与控制

活动任务保留到你删除或替换。应用在启动或回到前台时清理超过最近 30 天范围的完成历史；这不是后台定时删除保证，也不会删除你自行导出的备份、邮件或其他系统中的副本。

你可以在应用内删除任务、管理本机备份，并在系统设置中管理通知及提醒事项权限。卸载后的应用容器、偏好设置与系统备份如何保留取决于平台；macOS 移除应用程序本身不一定删除应用数据。系统提醒事项与已导出的文件也不一定随卸载删除。需要清理本机残留数据时，可联系支持获取操作说明。

支持邮件按处理请求所需时间保留；处理完毕后可通过上述邮箱请求删除我们持有的反馈信息。适用法律要求保留的记录除外。我们无法代你删除 Apple、GitHub、邮件服务商、云盘或他人已保存的副本，你可使用这些服务的相应控制和隐私请求渠道。
